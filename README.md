# Personal CV — Web Development & Automation

A responsive personal CV foundation inspired by the owner's older DevFreelance portfolio. Built with HTML, CSS, and JavaScript, with mobile navigation, category filters, project notes, scroll animation, reduced-motion support, and a print layout.

**Student name:** Irl Crishreg Peña

**Live Vercel link:** Not deployed yet.

## Run

Open index.html in a browser, or serve this folder with any static web server. No package installation or build is required. Internet access is optional for the Google Fonts; system fonts provide fallbacks.

## Files

- index.html: page content and semantic structure
- styles.css: layout, responsive breakpoints, animation, and printing
- script.js: navigation, filters, and print interaction
- vercel.json: static deployment configuration

## Personal content

Profile, portrait, school, skills, contact information, professional links, and four projects were reused from the owner's Portfolio School site with permission. The owner confirmed current 4th-year BSIT status and full development of NaviFlow and PitayaGrade. Academic/personal projects serve as experience. No awards, certifications, or formal roles were supplied, so those optional sections are omitted. College dates, project completion status, and individual project repository URLs were not supplied and are not invented.

## GitHub and Vercel

Create a dedicated personal GitHub repository and push this folder. Import that repository in Vercel, select Other as the framework, leave the build command empty, and use the repository root as the output directory. Deploy, then replace the live link above with the returned public URL.

Maintain meaningful commits while personalizing content, adding real assets, and fixing issues. Do not manufacture a development history or backdate commits. This starter's initial commit covers the foundation only.

## Submission checklist

- Real full name, title, portrait, introduction, objective, location, public email
- School, degree/program, current year, and applicable achievements
- Verified skills and real project information
- Working personal GitHub profile; optional LinkedIn/social profiles
- Applicable experience, certificates, and awards
- Test navigation, filters, project notes, and printing
- Check desktop, laptop, tablet, and phone layouts and keyboard navigation
- Publish to a personal GitHub repository and Vercel
- Verify both public URLs and submit them to the LMS

## Explain the implementation

HTML provides named sections and project content. CSS uses Grid and media queries for responsive layouts. JavaScript toggles the mobile menu, filters project cards, observes sections for animation, and opens the browser print dialog. No contact form or backend is included: the finished email contact should use a real mailto link.
